プライバシーポリシー

最終更新: 2026年10月22日

1. 概要

ytauto(以下「本ツール」)は、運営者本人が所有する YouTube チャンネルに動画をアップロード・予約投稿し、その公開状態と統計を確認するための個人用ソフトウェアです。本ツールは運営者のローカル PC 上で動作し、第三者にサービスとして提供されません。

2. 利用する Google API とデータ

本ツールは YouTube Data API v3 および YouTube Analytics API を使用し、運営者が明示的に許可した Google アカウントについて、次のデータにアクセスします。

  • 動画のアップロード、メタデータ(タイトル、説明、タグ、公開設定、サムネイル)の設定
  • 動画の公開状態・再生回数などの統計情報の取得
  • 再生リストへの追加

3. データの保存と共有

取得したデータおよび OAuth トークンは、運営者のローカル PC 内にのみ保存されます。第三者への提供・販売・外部サーバーへの送信は行いません。Google ユーザーデータは、YouTube API サービス利用規約および Google API サービス ユーザーデータ ポリシー(限定的使用の要件を含む)に従って取り扱います。

4. データの削除

運営者は、ローカルに保存されたトークンとデータをいつでも削除できます。また、Google アカウントの権限設定から本ツールのアクセス権を取り消すことができます。

5. YouTube の規約

本ツールは YouTube API サービスを使用しています。利用者は YouTube 利用規約 および Google プライバシーポリシー にも従います。

6. お問い合わせ

本ポリシーに関する問い合わせは、Google Cloud プロジェクトに登録された連絡先メールアドレス宛にお願いします。
